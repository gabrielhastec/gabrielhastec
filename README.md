Repositório de aprendizado estruturado que documenta minha evolução técnica desde os fundamentos do Java até o ecossistema Spring.

**Contexto:** Ingressei na Engenharia de Computação sem experiência prévia em programação. O desafio era construir uma base técnica sólida em paralelo à graduação.

**Abordagem:** Cada aula e exercício é versionado individualmente, criando um histórico real e mensurável de evolução. Após consolidar o Java Core — lógica de programação, POO, tratamento de exceções e boas práticas — avancei para o Spring Framework como próximo estágio de maturidade técnica.

**Resultados:**

### 🛒 PokePDV — Sistema de Ponto de Venda
> `Java` · `Spring Boot` · `React` · `SQL` · 🟡 Em desenvolvimento

Sistema SaaS de PDV voltado a pequenas e médias empresas que ainda dependem de controles manuais para gestão de vendas e estoque.

**Contexto:** Minha formação em Administração me expôs diretamente ao problema: PMEs operam sem ferramentas acessíveis de PDV, resultando em controle financeiro fragmentado e baixa rastreabilidade operacional.

**Abordagem:** Antes de qualquer linha de código, o projeto foi iniciado pela arquitetura: mapeamento de entidades, regras de negócio e fluxos operacionais. O stack combina **Java + Spring Boot** no backend (API REST), **React** no frontend e **SQL** para persistência, com estrutura orientada ao domínio do negócio.

**Resultados esperados:**
- Eliminação de controles manuais em planilhas
- Redução do tempo de registro de vendas
- MVP funcional cobrindo as operações core de PDV
- Base para evolução como produto SaaS acessível

🔗 [Ver repositório →](https://github.com/gabrielhastec/PokePdv)
